# FitLife AI Planner

React + Vite starter for Cloudflare Pages.

## Local development

```bash
npm install
npm run dev
```

## Cloudflare Pages
- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`

## Migration status
This repository contains the original uploaded React source wrapped in a Vite scaffold. It is not yet a verified complete transfer of the latest Floot changes or database/authentication state. Keep the Floot project intact until feature parity and data migration are checked.
