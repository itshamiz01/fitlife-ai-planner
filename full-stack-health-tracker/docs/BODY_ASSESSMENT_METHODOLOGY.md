# Body screening methodology — v1 draft

This is an isolated arithmetic module, `src/lib/body-assessment.ts`, not a released assessment screen, medical diagnosis, exercise clearance, goal, weight prescription, or clinically validated algorithm. It does not change existing profiles, plans or records. See `BODY_WORKOUT_ARCHITECTURE_PLAN.md` for evidence and rollout gates.

For ages 20–110 who explicitly indicate standard applicability, BMI is kg/(height in metres)². Adult categories use raw BMI <18.5, 18.5 to <25, 25 to <30, and ≥30. BMI and reference weights are rounded to one decimal for display; classification uses unrounded BMI, so an apparent rounded boundary can have the lower category. The requested reference range is 18.5 × height² to 24.9 × height² in kg, rounded to 0.1 kg. 24.9 is a conventional displayed upper value, not the exact mathematical endpoint of the <25 category. This range is population-based, not an exact healthy or ideal weight for an individual. BMI does not measure body fat or differentiate muscle, fat, and bone or distribution; it is screening only. Category thresholds and range do not vary by sex or gender.

When the user explicitly selects an Asian population reference, the result additionally reports <23, 23 to <27.5, or ≥27.5 public-health action points, computed from unrounded BMI. These are separate from international categories, not an individual diagnosis or an Asian ideal-weight formula. Country does not determine ancestry. When another reference or unspecified is selected, the Asian action point is absent, not assumed normal.

An optional waist/height ratio is computed with both measures in cm. For BMI below 35, it returns whether the unrounded ratio is below 0.5 or at/above 0.5; this is a simplified screening flag, not diagnosis, assurance of low risk, or a clinical classification. For BMI ≥35 the ratio can be shown but is explicitly not interpreted because NICE's cited scope is BMI below 35. Hip circumference and body-fat percentage are passed through only if supplied; none are inferred. Values are validated against broad product limits, not clinical norms. UI must explain missing values, measurement limitations, screening scope and professional review.

No values or categories are calculated for anyone under 20. WHO uses a growth reference through age 19 while CDC's adult categories start at 20; this conservative product boundary avoids applying adult cutoffs before a validated age-specific approach is implemented. Pregnant/postpartum users and users unsure whether standard assessment applies are directed to clinical guidance instead of receiving automatic categories. `standard` is an explicit indication by the user, not medical clearance, and screening still needs clinical context. Age and clinical context gates do not prescribe any exercise, nutrition or weight change. Unit conversion uses exact international pound and inch factors; all assessment inputs are normalized to kg/cm before calculation.

Sources: [CDC BMI limitations and age scope](https://www.cdc.gov/bmi/about/index.html), [CDC interpretation](https://www.cdc.gov/bmi/faq/index.html), [WHO growth reference](https://www.who.int/tools/growth-reference-data-for-5to19-years/indicators/bmi-for-age), [WHO Expert Consultation, Lancet 2004](https://pubmed.ncbi.nlm.nih.gov/14726171/), [NICE NG246 waist-to-height rationale](https://www.nice.org.uk/guidance/ng246/chapter/Rationale-and-impact). None validates this software or a personalized training plan.

Run `node scripts/verify-body-assessment.cjs` for synthetic arithmetic, threshold, safety-gate and conversion tests. Not tested clinically, with actual patients, or through the UI; no historical body assessments are stored. Medical screening, training generation, a calendar, progression, integration and the requested end-to-end system remain to be implemented.

## Optional local profile view (development)

The development profile UI offers an opt-in screen using the saved age, height, current weight, fitness focus and target weight. Unsaved form edits are not used. Applicability must be explicitly selected; pregnancy/postpartum, uncertainty and under-20 age gate screening output. The optional South Asian, East Asian and Southeast Asian selections each map to the same general Asian public-health action points; this is not a claim that these groups have identical risk. European/other and unspecified do not display Asian thresholds. Selection and results remain in component state and are not sent to the server or stored. No goal, profile, workout or meal plan is changed. This development UI and arithmetic remain unvalidated clinically and must not be described as personalized diagnosis or medical clearance.
